# Changelog

Generated at the release cut, newest first, and never edited by hand.
Each section holds the conventional commit subjects between the previous
tag and its own — the same material the forge's generated notes read;
what changes is that a checkout answers "what changed" without leaving
it.

One writer is the whole point. An entry that is wrong is wrong in the
subject that produced it, and that is where it is fixed, on the next
tag. Nothing here is back-filled: the file starts at the first tag cut
after it shipped.
