# Routes

- Homebrew: `brew install thomasfranke/tap/writrun` — the cask is
  `writrun`, the installed binary is `writrun`. A cask and not a
  formula: GoReleaser deprecated formula generation, and
  `goreleaser check` exits 2 on a configuration asking for one.
- Prebuilt binaries per platform on tagged GitHub releases.
- `go install github.com/thomasfranke/writrun-cli/cmd/writrun@latest`.
