# terminal interaction via the Charm stack, `github.com/charmbracelet/huh` at the surface.

**2026-09-03**

Arrow-key selection, confirmation, the one free-text prompt and the
spinner for waits come from one maintained family (huh over Bubble
Tea, with Lip Gloss), behind the term port; if screens ever appear,
the engine is already present. Rejected: hand-rolling raw mode over
`x/term` (key decoding, wrapping and resize re-implemented for three
prompts), tview/tcell (a widget toolkit for an app that asks
questions), and numbered menus (the product rule keeps arrow keys).
