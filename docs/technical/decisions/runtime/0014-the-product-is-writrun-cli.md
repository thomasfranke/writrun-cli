# the product is `writrun-cli`; the command stays `writrun`.

**2026-09-09**

What the binary says about itself — `--version`, `--help`, the screens'
header — names `writrun-cli`. What a person types is unchanged.

This supersedes [0005](0005-the-binary-is-writrun.md), which rejected a
second name when the second name was `writ`: four letters saved, and a
reader who knows one form cannot guess the other. The case here runs the
other way. The methodology is `WritRun` and the client was `writrun`,
which differ by capitalisation alone — a reader hears no difference, and
a screen naming both in one line reads as one thing twice. `writrun-cli`
is the name the repository, the module and the Homebrew formula already
carry, so the surface gains no name that did not exist; it stops hiding
one.

Rejected: renaming the executable too — the command is muscle memory and
a path in every adopter's scripts, and 0005's argument holds for it
exactly.
